# Assets Explorer Website

This repository implements a dynamic assets explorer website for datasets and research papers.
The website automatically discovers and displays explorers based on `info.jsonl` files located in subdirectories under the `assets/` folder.
Each explorer shows a list of assets with filtering capabilities through a tagging system.
Users can click on asset cards to view full details.

## Viewing the Website Locally

The simplest way to view your assets explorer is to serve the static website through a local HTTP server.
Clone the repository if you have not done it:

```bash
git clone git@github.com:fairinternal/AssetExplorer.git
cd AssetExplorer
```

Serve the website locally:

```bash
cd docs
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your web browser.
This will show you the complete website with all your assets and explorers, with fully functional navigation!
For privacy reasons, the website is not hosted remotely.

## Modifying the Website

The website automatically discovers content based on your folder structure. Here's how to add and modify content:

#### Adding a New Explorer

To add a new explorer to the website:
Create a new directory under `assets/` with your explorer name:

```
assets/my_new_explorer/
```

Add an `info.jsonl` file in the directory with explorer metadata:

```json
{
    "title": "My New Explorer Title",
    "description": "A brief description of this explorer (optional)"
}
```

Add a `tags.jsonl` file defining the tags for this explorer:

```json
[
    {
        "group": "Source",
        "tags": {
            "human": "data generated by humans",
            "synthetic": "data generated by machines"
        }
    }
]
```

The new explorer will automatically appear on the homepage after you rebuild the website!

#### Adding Assets to an Explorer

To add a new asset to an existing explorer:
Navigate to the appropriate explorer directory under `assets/`.
Create a new JSON file with the asset information (e.g., `my_asset.json`).
Follow the existing JSON structure and tagging conventions used in other files in the same directory.
The asset will automatically appear in the explorer after rebuilding.

## Building the Website

After making changes to your assets or explorers, you need to rebuild the static website:

#### Prerequisites

First, set up your environment:

```bash
# Clone the repository (if you haven't already)
git clone https://github.com/fairinternal/AssetExplorer.git
cd AssetExplorer

# Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install flask frozen-flask
```

#### Build the Static Website

Run the deploy script to generate the static HTML files:

```bash
python scripts/deploy.py
```

This will update the `docs/` folder. You can then view the website by following the instructions above.

#### Development Mode (Optional)

For active development with live reloading, you can run the Flask development server:

```bash
python scripts/build.py
```

Then open [http://localhost:5000](http://localhost:5000) in your browser. Changes will be visible immediately when you refresh the page.

#### Utility Scripts

This repository includes several utility scripts to help manage and update your assets.
For example, the `check_tags.py` script verifies tag consistency across your assets:

```bash
python scripts/check_tags.py
```

This will report:

* Assets using undefined tags
* Defined tags that are never used
